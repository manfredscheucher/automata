// Input: a decimal number n
// Output: n in binary, most significant bit on the left (13 -> 1101)
// Simulator: https://turingmachinesimulator.com
//
// Halves the number again and again, from left to right like long division.
// The state remembers the remainder so far (halve0, halve1). At the right end
// the remainder is the next bit. It goes in front of the bits behind the #,
// so the most significant bit ends up on the left.
// Tape: <number> # <bits>
// See also the "Decimal to binary" example on turingmachinesimulator.com,
// which halves from right to left.
