// a binary string by concatenating
// the string to its mirror image.
// i/o will be used as "markers" for
// the squares with 1's and 0's
// (respectively).

// Modified 2026 by Manfred Scheucher: generalized from 0,1 to 0,1,2,3
// (markers o,i,j,k), and removed rules that never run
// (qinit on markers, removing_the_markers on digits).
